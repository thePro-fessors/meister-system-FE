# 마이스터역량인증제 관리 시스템 (프론트엔드)

Next.js(App Router) + TypeScript + Tailwind CSS로 구현한 프론트엔드 전용 프로젝트입니다.
백엔드 없이 브라우저의 localStorage/sessionStorage에 목(mock) 데이터를 저장하여 동작합니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 접속

## 구현된 기능

- 로그인 / 로그아웃 / 권한별 화면 분기 (요구사항 3장)
- 학생: 인증 현황 조회, 증빙자료 제출(+AI 자동 분류 추천), 제출 내역/재제출, 상벌점 내역 (5장)
- 교사: 대시보드, 학생 자료 조회, 증빙자료 검토(승인/반려), 점수 부여, 상벌점 관리 (6장)
- 관리자: 학년도 관리, 학년별 기준·배점·산정방식 관리, 전체 현황 (7장)
- AI 기능①: 증빙자료 제출 시 세부항목/설명 텍스트를 키워드 기반으로 분석해 인증 영역·평가 항목을 자동 추천 (`src/lib/ai.ts`)
- AI 기능②: 학생 화면 전체에 떠 있는 **AI 학생 도우미 챗봇** — 내 총점/영역별 등급/부족한 영역/상벌점/반려 사유/제출 방법/등급 기준 등을 학생 데이터 기반으로 즉시 답변 (`src/lib/chatbot.ts`, `src/components/StudentChatbot.tsx`)

## 참고 사항

- 이 프로젝트는 **프론트엔드 전용**이며 모든 데이터는 브라우저에 저장됩니다(새로고침해도 유지, 다른 브라우저와는 공유되지 않음).
- 실제 서비스로 확장하려면 `src/context/DataContext.tsx`의 CRUD 함수들을 백엔드 API 호출로 교체하면 됩니다.
- 로그인과 권한 검사는 데모용 클라이언트 로직입니다. 계정/비밀번호와 데이터가 브라우저에 노출되므로 실제 학생 정보를 입력하지 마세요. 운영 서비스에는 서버 인증, 서버 측 권한 검사, 안전한 비밀번호 저장이 필요합니다.
- 파일 첨부는 파일명만 저장하며 실제 파일 업로드/다운로드는 지원하지 않습니다. 증빙 확인이 필요하면 HTTP(S) 링크를 사용하세요.
- 상벌점의 학년도는 발생일 기준 3월부터 다음 해 2월까지입니다. 기존 기록도 같은 규칙으로 계산합니다. 평가 항목별 합산은 최대점을 넘지 않으며, 최상위인정형은 최고 점수만 반영합니다.
- 나이스 API 연동 등 외부 연동은 백엔드가 필요하므로 이번 프론트엔드 구현에는 포함되어 있지 않습니다.
